Mockup notes — deliberate simplifications
  • Navigation is toasted, not routed; recompute is a fake 2 s run that reuses the real disabled-while-running + overlay behavior and leaves every number unchanged.
  • The self-reserve notch (Ledger) is drawn on the row's own scale but visually capped — a torn left edge marks the clip; the tooltip always carries the absolute u/d (cap convention: graphics cap, printed numbers never do).
  • The fleet matrix uses chain/lane columns instead of consumer-plan columns — fleet claims are per lane/chain, not per plan.
  • The Map covers material rows only; fleet lanes/chains have no plan-to-plan flow to draw — the Ledger and Matrix carry the fleet domain.
  • Hired lanes claim no own ship time (spec), so the hired Promitor → Montem MCG lane appears in no fleet row.
  • Blocks sizes boxes by draw share (subscribed ÷ net) by default because treemap areas would otherwise mix u/d with ship-min/d across branches; the absolute toggle stays available but carries a visible amber caveat in the subtitle. Rows with no denominator get a fixed hatched area — area never claims a utilization. Zoom is a re-render with a light fade, not a tweened transition.
  • Bubbles keeps two radius scales (materials vs fleet) so units never share one scale; the layout is a deterministic relaxation (~90 iterations at render), not a physics simulation. Tiny bubbles label on hover only, and the drill-down renders as a detail panel below the field rather than a literal in-place expansion.
  • Beeswarm shares one utilization axis (dimensionless) but keeps two size lanes so u/d and ship-min/d radii never share a scale. The dodge is a deterministic greedy scan (sorted by utilization, alternating vertical offsets), not a force simulation. Rows past the 250% axis cap pin at the torn edge with the uncapped % printed; null-utilization rows sit in the hatched gutter, never on the axis. The click drill-down is a single-row mini-ledger below the field, not an in-place zoom.
  • Dumbbell uses one absolute linear scale per unit group (materials u/d, fleet ship-min/d — never shared). Line color states direction but never alone: the Δ is printed uncapped and the deficit carries ▲. Net ≤ 0 / no-ships rows park the hollow capacity dot in the hatched gutter left of the origin with a badge; the subscribed dot stays on the real scale.
  • Waffle squares are a rounded approximation — the per-row quantum targets 50–100 squares for capacity, largest-remainder allocation keeps each consumer within one square of its true value, and printed numbers stay exact and uncapped. Long tails clip: the self-reserve block caps at 12 hatched squares and overflow caps near 250% of capacity, both with the true counts printed at the clip. Overflow squares go flat red (consumer identity moves to the tooltip). Only the top 8 rows render by default — waffles are tall — with a show-all fold.
  • Blocks gained a load / headroom view toggle: headroom sizes boxes by max(net − subscribed, 0) ÷ net (dimensionless, so honest across units); over and no-denominator rows get a fixed minimal hatched box — zero headroom never earns area. The sizing toggle (share / absolute) applies to load view only, and the full row zoom keeps the load composition in either view.
